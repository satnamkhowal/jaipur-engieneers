Hadoop Distributed File System<\/strong><\/h3>\r\n

The Hadoop Distributed File System (HDFS) is created probably to collect very large data sets and to run those data at high bandwidth for user applications. In a large batch, Several servers, host directly connected storage and complete user administration tasks.     Hbase<\/strong><\/h3>\r\n

    HBase is a common-oriented database management system, it runs on the peak of HDFS.\u00a0 It is well adapted for rare input sets,\u00a0 which are popular in many big data practice examples. In a relational database system, the structured query languages like SQL\u00a0 doesn’t support\u00a0 HBase.<\/p>\r\n

    HBase applications are composed of Java-like Typical MapReduce applications. Written applications in Avro, REST, and Thrift are supported by HBase.<\/p>\r\n

    Features:<\/strong><\/p>\r\n\r\n

      \r\n \t
    • Modular and Linear Scalability.<\/li>\r\n \t
    • Strictly constant reads and writes.<\/li>\r\n \t
    • Configurable and Automatic sharding of Tables.<\/li>\r\n \t
    • Automatic failover maintenance between RegionServers.<\/li>\r\n \t
    • For client access, Java API is using it is very easy to use.<\/li>\r\n<\/ul>\r\n

      HIVE<\/strong><\/h3>\r\n

      With the Apache Hive Data Storage software, large datasets in distributed storage can be queried and managed. Hives afford a device to project structure onto this data and query, the data using a SQL-like language called HiveQL.<\/p>\r\n

      Features:<\/strong><\/p>\r\n\r\n

        \r\n \t
      • Various storage types such as plain text, HBase, ORC and other.<\/li>\r\n \t
      • The running compressed data are stored in the ecosystem of Hadoop. The algorithm including bzip2, gzip, snappy, etc.<\/li>\r\n \t
      • \u00a0DBMS have metadata storage, During execution, it can reduce the time for performing the semantics checks<\/li>\r\n<\/ul>\r\n

        Sqoop is a designed tool for transferring the data between the relational database and Hadoop. It can carry the data to Hadoop Distributed File System (HDFS) from Relational DBMS (RDBMS). The data that carry into Hadoop MapReduce will return into an RDBMS.<\/p>\r\n

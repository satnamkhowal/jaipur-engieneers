Lists In Python<\/h3>\r\n

A list contains is a collection of multiple elements or items or arbitrary objects (in the programming sense).They are like arrays in the other languages but more versatile and flexible. <\/p>\r\n

\r\n

Eg:<\/p>\r\n

my_list=[1,‘fita’,’training’,[‘chennai’,’bangalore’],3]<\/p>\r\n<\/div>\r\n

Characteristics Of Lists<\/h3>\r\n
\r\n
<\/i> Lists are ordered i.e., their order is reserved after they are defined(unlike dictionaries or sets).<\/div>\r\n
<\/i> Lists are mutable i.e., their elements can be changed,or resized(unlike tuple or string).<\/div>\r\n
<\/i> Lists can contain elements with different data types with a finiteness.<\/div>\r\n
<\/i> Lists items can be concatenated<\/div>\r\n
<\/i> You can use logical operators with lists to test conditions.<\/div>\r\n<\/div>\r\n

Methods In Lists<\/strong><\/p>\r\n

\r\n
<\/i> Any element can be accessed using square brackets[] notation or .index(x) method.<\/div>\r\n<\/div>\r\n

{Note that the indexing starts at 0}<\/p>\r\n

\r\n
<\/i> Elements can be appended to lists with the .append(x) , .insert(i,x) or .extend(iterable) method.<\/div>\r\n
<\/i> Elements can be removed from the lists with the .remove(x) or .pop() or .clear() element.<\/div>\r\n
<\/i> Elements can be changed by accessing and then assigning using = operator.<\/div>\r\n
<\/i> Elements can be concatenated and returned as a single object with .join() method.<\/div>\r\n
<\/i> A string can be converted to a list with the list() method.<\/div>\r\n<\/div>\r\n

Program 1: Finding the length of list using len method<\/h3>\r\n

len is a built-in method in python which returns the size of the object passed to it, irrespective of the index of last element.When a string is passed as an argument it returns the number of characters in the string.It is often used technique in programs these days.<\/p>\r\n

\r\n

my_list=[]<\/p>\r\n

my_list.append(‘hello’,’readers’)<\/p>\r\n

print(‘length of our list: ‘,len(my_list))<\/p>\r\n

Output:<\/strong><\/p>\r\n

Length of our list: 3<\/p>\r\n<\/div>\r\n

Program 2: Finding the length of list with a custom method.<\/h3>\r\n
\r\n

my_list=[0,1,1,2,3,5]<\/p>\r\n

counter=0<\/p>\r\n

for _ in my_list:<\/p>\r\n

counter+=1<\/p>\r\n

print(‘size of list with my method: ‘,counter)<\/p>\r\n

 <\/p>\r\n

Output:<\/strong><\/p>\r\n

size of list with my method: 6<\/p>\r\n<\/div>\r\n

Program 3: Find the length of the nested list<\/strong><\/h3>\r\n

Nested lists have lists as an element in them. You can consider a nested list as a matrix..We can find the length of such lists, The length of the list can be using len method and the length of a sub list can be found by passing the sub list as argument to len method.<\/p>\r\n

\r\n

my_list=[[‘list 1’,‘element 1’,’element 2’],[‘list 2’, ‘element 1’, ‘element 2’]]<\/p>\r\n


print(‘length of the list: ’,len(my_list)) <\/p>\r\n

print(‘length of the first sub list: ’,len(my_list[0]))<\/p>\r\n

 <\/p>\r\n

Output: <\/strong><\/p>\r\n

length of the list: 2<\/p>\r\n

length of the first sub list: 3<\/p>\r\n<\/div>\r\n

The other ways to find the length of the list includes using length_hint() and __len__ method. Now you can also write your own unique program to find the length of the nested list using for or while loops.<\/p>\r\n

Time Complexity Of len function<\/strong><\/h3>\r\n

len() function actually calls the __len__ method internally to return the size of the object and every object (list, tuple, set, dictionary, set, array.array) has its own __len__ method, so all it does is return self.length.<\/p>\r\n

So the time complexity of the len() method is O(1) (in big-O notation) or constant time.<\/p>\r\n

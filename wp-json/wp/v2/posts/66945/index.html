What Is Numpy?<\/h3>\r\n

Numpy or Numerical python is a free and open source library for working with n-dimensional arrays or ndarrays.It is often used with other libraries such as scipy,matplotlib,Pandas,scikit for scientific computations for various data science or machine learning<\/a> applications.Numpy is partly written in Python and the rest with C C++<\/a>.<\/p>\r\n\r\n

Python Lists Vs Numpy Arrays<\/h3>\r\n

In python we used lists for storing multiple data instead of arrays, because arrays can only include homogenous data or elements of the same data type.Then why use arrays instead of lists?<\/p>\r\n

Array elements are stored at contiguous memory locations,and use less memory and space which make them convenient to use.<\/p>\r\n

Consider the following example where we are adding numbers,(1 to 100000 with 1 to 100000) with lists and arrays and comparing their time difference (with time module) to do this math.<\/p>\r\n\r\n\r\n\r\n\r\n
import time\r\n\r\nimport numpy as np\r\n\r\nvector = 100000\r\n\r\n \r\n\r\ndef pure_python_ver():\r\n\r\nt = time.time()\r\n\r\nx = range(vector)\r\n\r\ny = range(vector)\r\n\r\nz = [x[i] + y[i] for i in range(len(y))]\r\n\r\nreturn time.time() – t\r\n\r\n \r\n\r\ndef numpy_ver():\r\n\r\nt = time.time()\r\n\r\nx = np.arange(vector)\r\n\r\ny = np.arange(vector)\r\n\r\nz = x + y\r\n\r\nreturn time.time() – t\r\n\r\n \r\n\r\nt1 = pure_python_ver()\r\n\r\nt2 = numpy_ver()\r\n\r\n \r\n\r\nprint(‘time taken by python version:’,t1)\r\n\r\nprint(‘time taken by numpy version: ‘, t2)\r\n\r\nprint(“Numpy is” + str(t1\/t2) + ” faster!”)<\/td>\r\n<\/tr>\r\n<\/tbody>\r\n<\/table>\r\nOutput\r\n\r\n\r\n\r\n

Slicing Elements from the array<\/h3>\r\n
\r\n
<\/i> For 1-D arrays<\/div>\r\n<\/div>\r\nWe\u2019ll have the same slicing method as the list that is using indexing or [start:end:step].\r\n\r\n\r\n\r\n
arr = np.array([1, 3, 5, 7, 11, 13, 17])\r\n\r\n \r\n\r\nprint(arr[1:7:2]) #output: [ 3 7 13]<\/td>\r\n<\/tr>\r\n<\/tbody>\r\n<\/table>\r\nThe above program returns every element from index 1 to index 7 by skipping 2 elements in between.\r\n
\r\n
<\/i> For 2-D arrays<\/div>\r\n<\/div>\r\nWe will have to specify the slicing for both the rows and column, separated by a comma respectively.\r\n\r\n\r\n\r\n
arr = np.array([[1, 1, 2, 3, 5], [1, 2, 3, 5, 7]])\r\n\r\n \r\n\r\nprint(arr[1, 2:5]) # outputs [3 5 7]<\/td>\r\n<\/tr>\r\n<\/tbody>\r\n<\/table>\r\nHere the program slices for row 1 and for the columns of the respective row 1 it gives values from index 2 to index 5.\r\n\r\nAnother example for slicing 2-D arrays\r\n\r\n\r\n\r\n
arr = np.array([[1, 1, 2, 3, 5],\r\n\r\n[1, 2, 3, 5, 7]])\r\n\r\n \r\n\r\nprint(arr[0:2, 2:4])<\/td>\r\n<\/tr>\r\n<\/tbody>\r\n<\/table>\r\nHere we are taking rows from 0 to 1(2 excluded because of colon) and printing values from index 2 to index 3 (4 excluded because of colon).\r\n\r\nOutput\r\n\r\n\r\n\r\n
[[2 3]\r\n\r\n[3 5]]<\/td>\r\n<\/tr>\r\n<\/tbody>\r\n<\/table>\r\n

Copy And View In Numpy<\/h3>\r\n

The difference between view and copy of an array is that the former one(view) will create a new array with the elements as of the parents elements,but changing any of the elements of either the parent\u2019s or the view copy\u2019s element will be reflected in both the arrays.Whereas the later one(copy) is like deep copy of lists, where changing elements of either the parents or the copied array will not change the other one.<\/p>\r\n\r\n

Statistics with Numpy<\/h3>\r\n
\r\n
<\/i> Estimate mean with numpy<\/div>\r\n<\/div>\r\nThe mean of a data set is the average value or the sum of values divided by the number of values.We can calculate the mean of any data set with numpy.mean().\r\n\r\nNow let us find the average value of the speed of the given 10 people.\r\n\r\n\r\n\r\n
speed = [91, 20, 81, 86, 120, 86, 91, 122, 91, 78]\r\n\r\n \r\n\r\nx = np.mean(speed)\r\n\r\n \r\n\r\nprint(x) # output: 86.6<\/td>\r\n<\/tr>\r\n<\/tbody>\r\n<\/table>\r\n
\r\n
<\/i> Estimate median with numpy<\/div>\r\n<\/div>\r\nMedian is the middle most value of the given values, after arranged in ascending or descending order,we can calculate the median of any data set with numpy.median().\r\n\r\nNow let’s calculate the middle most value(where all the values surround) for those 10 people\u2019s speed.\r\n\r\n\r\n\r\n
speed = [91, 20, 81, 86, 120, 86, 91, 122, 91, 78]\r\n\r\n \r\n\r\nx = np.median(speed)\r\n\r\n \r\n\r\nprint(x) # output: 88.5<\/td>\r\n<\/tr>\r\n<\/tbody>\r\n<\/table>\r\n
\r\n
<\/i> Estimate Percentile with numpy<\/div>\r\n<\/div>\r\nA Percentile shows the percentage of the values that are less than the given value,we can calculate percentile with numpy.percentile().\r\n\r\nNow let us calculate the speed where the percentage of speed is 50 or less than that.\r\n\r\n\r\n\r\n
speed = [91, 20, 81, 86, 120, 86, 91, 122, 91, 78]\r\n\r\n \r\n\r\nx = np.percentile(speed, 34)\r\n\r\n \r\n\r\nprint(x) # output: 86.0<\/td>\r\n<\/tr>\r\n<\/tbody>\r\n<\/table>\r\nThe mode of the data set can be calculated with the scipy library of python.\r\n
\r\n
<\/i> Estimate standard deviation with numpy<\/div>\r\n<\/div>\r\nThe standard deviation indicates how far the values are from the mean or the sum of the difference of the value from the mean, we can calculate the standard deviation with numpy.std()\r\n\r\nNow lets calculate the standard deviation of the speeds registered.\r\n\r\n\r\n\r\n
speed = [91, 20, 81, 86, 120, 86, 91, 122, 91, 78]\r\n\r\n \r\n\r\nx = np.std(speed)\r\n\r\n \r\n\r\nprint(x) # output: 26.3977271748914<\/td>\r\n<\/tr>\r\n<\/tbody>\r\n<\/table>\r\n
\r\n
<\/i> Estimate variance with numpy<\/div>\r\n<\/div>\r\nVariance is the square root of the standard deviation.We can estimate the variance using numpy.var().\r\n\r\nNow calculate how far the values are from the mean and every other value.\r\n\r\n\r\n\r\n
speed = [91, 20, 81, 86, 120, 86, 91, 122, 91, 78]\r\n\r\n \r\n\r\nx = np.var(speed)\r\n\r\n \r\n\r\nprint(x) # output: 696.8399999999999<\/td>\r\n<\/tr>\r\n<\/tbody>\r\n<\/table>\r\n

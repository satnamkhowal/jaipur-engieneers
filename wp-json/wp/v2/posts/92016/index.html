                                  <\/i><\/i>Q89<\/span>. Why should I use Azure ACS instead of relying on ADFS?<\/a><\/h4>\r\n<\/div>\r\n
                                  \r\n
                                  \r\n

                                  The purpose of Azure Active Directory Federation Services (AD FS) is to allow identity providers to authenticate users against another directory service. The federation server can act as the authentication proxy and pass messages back to the Identity Provider (IdP). It also supports Single Sign On (SSO), which allows a user to skip entering user credentials during subsequent interactions with the IdP. However, the main drawback of AD FS is that it requires a dedicated infrastructure component called Federation Server.<\/p>\r\n\r\n<\/div>\r\n<\/div>\r\n<\/div>\r\n

                                  <\/i><\/i>Q90<\/span>. What are the components of an Azure Load Balancer?<\/a><\/h4>\r\n<\/div>\r\n
                                  \r\n
                                  \r\n

                                  A load balancer distributes incoming traffic across multiple targets, typically servers, so that each target receives roughly equal traffic. A load balancer has a front end that accepts client requests and a backend that dispatches those requests to one of its available targets. The load balancer sends the request to one of the targets, waits for the response to arrive, and repeats the process until all targets have received the same number of requests.<\/p>\r\n\r\n<\/div>\r\n<\/div>\r\n<\/div>\r\n

                                  \r\n
                                  \r\n

                                  <\/i><\/i>Q91<\/span>. What is the difference between Application Gateway and WAF?<\/a><\/h4>\r\n<\/div>\r\n
                                  \r\n
                                  \r\n

                                  The application gateway acts as a firewall to protect resources within the cloud. It ensures that all incoming data passes through the gateway to reach the destination. An Application gateway is not aware of the actual content of the data being transferred. It simply routes the message to the next hop. In contrast, a web application firewall (WAF) inspects every HTTP request and blocks any malicious activity such as cross-site scripting attacks.<\/p>\r\n\r\n<\/div>\r\n<\/div>\r\n<\/div>\r\n

                                  \r\n

                                  Yes, we can use PowerShell cmdlets to interact with the Cloud shell. But, there is no support for some commands like “Get-AzureRmSubscription”, “Connect-AzAccount”, and “Remove-AzResourceGroup”. We need to use REST API or CLI to perform these operations.<\/p>\r\n\r\n<\/div>\r\n<\/div>\r\n<\/div>\r\n

                                  \r\n
                                  \r\n

                                  Microsoft Azure Multi-Factor Authentication enables organizations to create strong security controls by requiring multi-factor authentication (MFA) for accessing sensitive data. This helps prevent unauthorized access to confidential information. By using MFA, an organization can provide additional layers of protection for its assets. With this approach, only valid users who present two-factor authentication tokens can gain access.<\/p>\r\n\r\n<\/div>\r\n<\/div>\r\n<\/div>\r\n

                                  \r\n
                                  \r\n

                                  No, Azure AD does not use SAML. Instead, it uses OAuth 2.0 standard.<\/p>\r\n\r\n<\/div>\r\n<\/div>\r\n<\/div>\r\n

                                  \r\n
                                  \r\n

                                  Token encryption is used when sending passwords in clear text from your app to your ADFS instance. Token encryption provides added security because it encrypts the input before it’s sent to the federation server.<\/p>\r\n\r\n<\/div>\r\n<\/div>\r\n<\/div>\r\n

                                  <\/i><\/i>Q97<\/span>. What is Azure Key Vault?<\/a><\/h4>\r\n<\/div>\r\n
                                  \r\n
                                  \r\n

                                  Key vault stores cryptographic keys securely. These keys can be used to secure applications, services, networks, and devices. Using key vault makes it easier to manage and control the keys for different services, applications, and environments. You can store secrets in Azure Key Vault and access them directly from your apps without having to manage certificates and other infrastructure.<\/p>\r\n\r\n<\/div>\r\n<\/div>\r\n<\/div>\r\n

                                  \r\n
                                  \r\n

                                  The key clock feature allows you to synchronize keys stored in Key Vault with a local machine’s clock. This way, if the local computer loses power or time gets reset, the keys are still safe.<\/p>\r\n\r\n<\/div>\r\n<\/div>\r\n<\/div>\r\n

With Azure B2C, developers can quickly build identity management solutions that integrate business processes with customers, employees, partners, and suppliers.

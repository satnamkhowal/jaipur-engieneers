      Beginner level React Native interview question and answers<\/strong><\/h2>\r\n

      What is State and how does it work?<\/strong><\/h3>\r\n

      State is used to control the component. State also allows the value to store in it. State is mutable, hence it changes whenever you want. You can use state to store the information about the current screen. For example, let us say that we have a login form where we enter our username and password. We can save the entered credentials in the state and then display that information in the next screen. This way, we don’t have to pass those parameters again and again.<\/span><\/p>\r\n\r\n

      How Different is React-native from ReactJS?<\/strong><\/h3>\r\n

      React Native uses JavaScript for rendering views. It is based on the concept of components. Components are reusable building blocks which help developers build user interfaces easily. The main difference between <\/span>React JS<\/span><\/a> and react native is that React Native has its own API’s. These APIs allow developers to interact with the device. And they can access hardware features like camera or GPS etc.<\/span><\/p>\r\n\r\n

      Differentiate between Real DOM and Virtual DOM?<\/strong><\/h3>\r\n

      Real DOM: <\/b>In real DOM, every change made to the view will be reflected immediately. However, this approach is not efficient as it requires frequent updates. Hence, this approach is not recommended.<\/span><\/p>\r\n

      Virtual DOM:<\/b> In virtual DOM, only the changed parts of the view are updated. This helps in reducing the number of re-renders. Also, it provides better performance than the real DOM.<\/span><\/p>\r\n\r\n

      What is Redux in React Native?<\/strong><\/h3>\r\n

      Redux is a predictable state container. In addition to supporting web browsers, mobile devices, desktop computers, and serverless functions, it enables you to write applications that run across multiple environments.<\/span><\/p>\r\n

      This means the entire data flow in your application is handled inside a single container while persisting previous state. A Redux store contains three main parts:<\/span><\/p>\r\n\r\n

        \r\n \t
      • An action creator function-<\/strong> This takes care of dispatching events into your application.<\/span><\/li>\r\n \t
      • A reducer function-<\/strong> This receives the action and returns the next state based on the action type.<\/span><\/li>\r\n \t
      • A selector function-<\/strong> This selects the part of the current state that the component needs.<\/span><\/li>\r\n<\/ul>\r\n

        How to debug React Native Applications?<\/strong><\/h3>\r\n

        The first one is the Developer Menu. You can access it by pressing command+R on macOS or ctrl+M on Windows\/<\/span>Linux<\/span><\/a>.         For example, let’s say you want to find out why the component isn’t rendering correctly. To do that, you’d go into the Developer mode, and then select “React”.         What is Props Drilling?<\/strong><\/h3>\r\n

        Props drilling is an advanced technique where you pass props from parent components to child components. The idea behind this is to avoid passing unnecessary properties to children.<\/span><\/p>\r\n\r\n

        How to create a custom scroll view in React Native?<\/strong><\/h3>\r\n

        A ScrollView is a special kind of View which allows us to scroll through its content. We can add any number of Views inside a ScrollView.<\/span><\/p>\r\n\r\n

        What is the difference between Stateless Functional Components and Class Based Components?<\/strong><\/h3>\r\n

        Stateless functional components are functions that return JSX elements. They have no state, and they cannot interact with the outside world.<\/span><\/p>\r\n

        Class-based components are classes that extend Component class. These components can have state and they can call methods on their parents.<\/span><\/p>\r\n\r\n

        What is the difference Between React Hooks and Redux?<\/strong><\/h3>\r\n

        Hooks are a new addition to React 16.8.0. Hooks allow developers to reuse existing logic across different parts of the application.<\/span><\/p>\r\n

        Redux is a library that helps us manage our data. It has two main concepts: Actions and Reducers. An action is an object containing information about what happened in the UI. A reducer receives actions as input and returns a new version of the state.<\/span><\/p>\r\n\r\n

        What is the difference between PropTypes and TypeScript?<\/strong><\/h3>\r\n

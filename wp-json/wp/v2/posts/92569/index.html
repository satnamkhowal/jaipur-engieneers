                                              Prototypal Inheritance<\/b> – All the properties which are inherited from the parent object are copied to the newly created object when the parent object creates a new instance of itself.<\/p>\r\n\r\n<\/div>\r\n<\/div>\r\n<\/div>\r\n

                                              <\/i><\/i>Q85<\/span>. What do you mean by MEAN Stack?<\/a><\/h4>\r\n<\/div>\r\n
                                              \r\n
                                              \r\n

                                              There are four technologies in the MEAN stack \u2013 MongoDB, ExpressJS framework, AngularJS, and node.js \u2013 used to develop web applications. Developed by MongoDB founder Eliot Horowitz, it is best suited for prototyping, rapid development, and small projects. It is an ideal solution because it is easy to use and requires no server configuration.<\/p>\r\n

                                              MEAN stack is a popular choice among developers because it allows them to build fast and scalable web apps without having to learn complicated frameworks like Ruby on Rails or PHP. This makes it easier to build robust web applications.<\/p>\r\n\r\n<\/div>\r\n<\/div>\r\n<\/div>\r\n

                                              <\/i><\/i>Q86<\/span>. In ES6, what do you mean by Temporal Dead Zone?<\/a><\/h4>\r\n<\/div>\r\n
                                              \r\n
                                              \r\n

                                              Before ES6, variable declarations had to use one of three keywords: var, let, or const. These keywords define the scope of the variable, which determines where it can be used. For example, In JavaScript, global variables such as x can be referenced anywhere, whereas local variables are defined within functions.<\/p>\r\n

                                              With ES6, there are now two additional ways to declare variables: let and const. Let and const both introduce a new concept called block scoping. Block scoping allows us to specify what types of variables can be declared in different places. In particular, let and const are block-scoped; this means that they can only be accessed inside the curly braces ({}) that surround them. This makes them behave differently from regular variables.<\/p>\r\n

                                              Let and const don’t have temporal dead zones, meaning that they can be accessed before being assigned values. However, unlike normal variables, let and const aren’t hoisted to the top of the containing scope. Instead, they must be explicitly declared.<\/p>\r\n\r\n<\/div>\r\n<\/div>\r\n<\/div>\r\n

                                              \r\n

                                              Event Bubbling is the process whereby events propagate up the DOM tree until they reach the document root element (the HTML tag). Once at the document root, the event handler attached to the element receives notification about the event.<\/p>\r\n\r\n<\/div>\r\n<\/div>\r\n<\/div>\r\n

                                              <\/i><\/i>Q88<\/span>. What is event capturing in Java script?<\/a><\/h4>\r\n<\/div>\r\n
                                              \r\n
                                              \r\n

                                              In contrast to event bubbling, event capturing is the opposite of event propagation. Event capturing happens when an event propagates down the DOM tree instead of up. An event handler attached to an ancestor element will receive notification about the event. If the event handler does nothing with the event, then the event will bubble back up the DOM tree to the event source.<\/p>\r\n\r\n<\/div>\r\n<\/div>\r\n<\/div>\r\n

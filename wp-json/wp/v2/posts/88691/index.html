      How Azure works<\/strong><\/p>\r\n

      The entire concept of virtualization underpins Microsoft Azure. As a result, it has racks, just like any other virtualized data center. Each rack has its power supply and network switch, as well as a piece of software called Fabric-Controller. This Fabric-controller is a distributed program in charge of administering and monitoring the servers in the rack. In the event of a server failure, the Fabric-controller detects it and restores the service. And each of these Fabric-Controllers is linked to a piece of software known as Orchestrator. Web services and a Rest API for creating, updating, and deleting resources are included in this Orchestrator.<\/p>\r\n

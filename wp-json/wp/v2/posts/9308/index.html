What Is Selenium?<\/strong><\/p>\r\n

Selenium is the most powerful and open source automation testing tool, developed by Jason Huggins and his team. This testing framework is used to test the GUI and functionality of web applications. Released under Apache 2.0 license, this automation testing framework can be downloaded and used without any restrictions. Selenium is easy to get started with the help of FITA Selenium Course in Chennai<\/a> and it’s compatible with the most of the web browsers available in the market.<\/p>\r\n

Selenium offers a highly efficient way to generate test scripts, validate its functionality and, reuse such scripts in an automated framework. Once set up, the selenium automation testing framework executes the test cases in three modes.<\/p>\r\n\r\n

    \r\n \t
  • Selenium IDE<\/strong>– the record-playback mode, logs the test scenarios, and offers a good start to write tests, and group it together, to form a test suite.<\/li>\r\n \t
  • Selenium RC<\/strong>or remote-control mode launches multiple browsers, one at a time, and executes the pre-recorded test-cases.<\/li>\r\n \t
  • Selenium Grid<\/strong>records and replays Selenium IDE and RC test cases, to validate the tests.<\/li>\r\n<\/ul>\r\n

    Features Of Selenium:<\/strong><\/p>\r\n

    The selenium automation testing framework comes with several features that make the process of developing automated test scripts easy. It also offers a comfortable solution to test the large web application in smaller modules. Some of its features include easy to use interface, easier to create a unit test, exploratory tests, one bug reproduction tests, compatible with most of the web browsers and much more.<\/p>\r\n

    Selenium is the most robust testing framework and it works on all operating systems – Windows, Linux, Mac, Ubuntu, etc\u2026 and browsers in the market – Mozilla Firefox, Chrome, IE, Opera, and Safari. Selenium is also compatible with multiple programming languages like Perl, Python<\/a>, PHP<\/a>, Ruby, Java<\/a>, and .NET<\/a>. Software testers no need to use selenium’s own script to write test codes rather they use a programming language that they are familiar with. Also, it’s not necessary that the programming language used to develop the web application to be used for writing the test scripts. You can use the programming language that you are comfortable with.<\/p>\r\n

    Advantages Of Selenium Testing Framework:<\/strong><\/p>\r\n\r\n

      \r\n \t
    • Selenium is a pure open source, free to use and portable testing tool.<\/li>\r\n \t
    • Selenium comes with the different component to provide support to its parent which is Selenium IDE, Selenium Grid and Selenium Remote Control (RC).<\/li>\r\n \t
    • Selenium testing tool supports many operating systems like Windows, Macintosh, Linux, Unix etc.<\/li>\r\n \t
    • Selenium supports a variety of languages that include Java, Perl, Python, C#, Ruby, Groovy, JavaScript, and VB Script. etc.<\/li>\r\n \t
    • Selenium supports many browsers like Internet Explorer, Chrome, Firefox, Opera, and Safari etc.<\/li>\r\n \t
    • The selenium automation testing framework can be used with TestNG testing framework for testing our applications and generating reports.<\/li>\r\n \t
    • It can be integrated with Maven or ANT types of framework for source code compilation.<\/li>\r\n \t
    • Selenium can be also used for smart phones based application testing.<\/li>\r\n \t
    • It can be integrated with Hudson or Jenkins for continual integration.<\/li>\r\n \t
    • Selenium can be integrated with other open source tools for supporting other features.<\/li>\r\n \t
    • The Selenium automation testing framework requires less CPU and RAM resource for test script execution.<\/li>\r\n<\/ul>\r\n

      Disadvantages Of Selenium Automation Testing Framework:<\/strong><\/p>\r\n\r\n

        \r\n \t
      • The selenium automation testing tool requires strong technical skills. Software testers need to have the strong understanding of selenium tools as well as framework architecture.<\/li>\r\n \t
      • Selenium is only used to test web-based application and does not support windows or desktop based application.<\/li>\r\n \t
      • It is difficult to test Image-based application with the selenium automation testing framework.<\/li>\r\n \t
      • Selenium requires third party support for report generation activity like dependence on TestNG or Jenkins.<\/li>\r\n \t
      • Selenium does not have online support facility to the problem that testers face.<\/li>\r\n \t
      • Selenium does not support built-in add-ins support.<\/li>\r\n \t
      • Selenium does not support file upload facility.<\/li>\r\n \t
      • Selenium does not provide any built-in IDE for script generation and it needs other IDE like Eclipse for writing scripts.<\/li>\r\n \t
      • Selenium Automation Engineers are the bit in scarcity these days.<\/li>\r\n<\/ul>\r\n

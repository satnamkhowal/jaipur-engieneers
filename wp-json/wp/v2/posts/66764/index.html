Most often programmers make use of lists in programs while programming in python, and use arrays in other famous programming languages such as Java<\/a>, C, C++ etc. Well the common differences between a list and an array are<\/p>\r\n

\r\n
<\/i> Lists can store values with different data types, but arrays can only store values with the same datatype.<\/div>\r\n
<\/i> You won’t have to define datatype of elements in a list, but pass the data type of elements in array as first argument<\/div>\r\n
<\/i> Arrays are much faster and space efficient compared to lists.<\/div>\r\n<\/div>\r\n

So the arrays in python are a collection of elements of the same data type in an ordered sequence, on which the operations like insertion, deletion, traversing and updating can be performed. It is one of the data structures.<\/p>\r\n

Creating An Array In Python<\/h3>\r\n

Arrays unlike lists need to be imported in the program from the array module, and you can do it as so.<\/p>\r\n

Import array<\/h3>\r\n

You can also import every function from array so that you wont need to use the array.array() whenever you are using arrays in your program, like this<\/p>\r\n\r\n\r\n\r\n
\r\n

from array import *<\/p>\r\n<\/td>\r\n<\/tr>\r\n<\/tbody>\r\n<\/table>\r\n

The array(data type,elements) takes two positional arguments, data type such as integer,float,char,double,signed long,unsigned long <\/em>etc., and the second one as the values to be stored.<\/p>\r\n

Accessing elements from array<\/h3>\r\n

Accessing elements from an array is just as accessing elements from a list that is with indexing.Just keep in mind that indexing in programming starts at 0.<\/p>\r\n\r\n\r\n\r\n
\r\n

# Example program for accessing element from array<\/p>\r\n
\r\n

arr = array.array(‘i’,[1,2,3,4])<\/p>\r\n

first_elem_arr = arr[0]<\/p>\r\n

print(first_elem_arr)<\/p>\r\n<\/td>\r\n<\/tr>\r\n<\/tbody>\r\n<\/table>\r\n

Output<\/p>\r\n\r\n\r\n\r\n
\r\n

1<\/p>\r\n<\/td>\r\n<\/tr>\r\n<\/tbody>\r\n<\/table>\r\n

Further, the other elements can be found with the index, and the last element with an index -1, the last second with -2 index.<\/p>\r\n



<\/p>\r\n\r\n\r\n\r\n
\r\n

# Second example program for accessing element from array<\/p>\r\n
\r\n

arr_1 = array.array(‘i’,[1,2,3,4])<\/p>\r\n

arr_2 = array.array(‘i’,arr[0],arr[-1],arr[1],arr[-2])<\/p>\r\n

print(‘first,last,second,second last elements from the array 1 are: ’,arr_2)<\/p>\r\n<\/td>\r\n<\/tr>\r\n<\/tbody>\r\n<\/table>\r\n

Output<\/p>\r\n\r\n\r\n\r\n

first,last,second,second last elements from the array 1 are: array(‘i’,[1,4,2,3])<\/p>\r\n<\/td>\r\n<\/tr>\r\n<\/tbody>\r\n<\/table>\r\n

To get one element at a time, we can use for or while loops to iterate over the array and print the elements.<\/p>\r\n\r\n\r\n\r\n
\r\n

# Example program for accessing elements with for loop<\/p>\r\n
\r\n

print(i, end=’ ‘)<\/p>\r\n<\/td>\r\n<\/tr>\r\n<\/tbody>\r\n<\/table>\r\n

Also, you can use the slicing method to get specific elements from the array,<\/p>\r\n

The array_name[start:end:step] will return the elements in the array_name from the start index until the end index, by removing or skipping step number of elements in between.<\/p>\r\n\r\n\r\n\r\n
\r\n

# Example program for Slicing arrays<\/p>\r\n
\r\n

Adding elements to array<\/h3>\r\n

Elements can be added to the end of the arrays using the append() method as follows<\/p>\r\n\r\n\r\n\r\n
\r\n

# Example program for adding element to array<\/p>\r\n
\r\n

arr = array.array(‘i’,[1,3,6,12])<\/p>\r\n

print(‘Array before: ‘,arr)<\/p>\r\n

arr.append(3)<\/p>\r\n

print(‘Array after: ’,arr)<\/p>\r\n<\/td>\r\n<\/tr>\r\n<\/tbody>\r\n<\/table>\r\n

Output<\/p>\r\n\r\n\r\n\r\n
\r\n

Array before: array(‘i’,[1,3,6,12])<\/p>\r\n

Array after: array(‘i’,[1,3,6,12,3])<\/p>\r\n<\/td>\r\n<\/tr>\r\n<\/tbody>\r\n<\/table>\r\n

Elements can be added at a specific index using .insert() method.The insert() method takes two positional arguments , first as the index and second as the value to be inserted.The index of all the elements will be updated after an insert method.<\/p>\r\n

The index of any element can be found using the iterable.index(value) method.<\/p>\r\n

The index method will return -1 if the index is not found for the passed parameter.<\/p>\r\n\r\n\r\n\r\n
\r\n

# Example program for inserting element to array at specified index<\/p>\r\n
\r\n

arr = array.array(‘i’,[1,3,6,12])<\/p>\r\n

arr.insert(0,1)<\/p>\r\n

print(‘Array after inserting element at first position:’,arr)<\/p>\r\n

print(‘index of last element: ’,arr.index(arr[-1]))<\/p>\r\n<\/td>\r\n<\/tr>\r\n<\/tbody>\r\n<\/table>\r\n

Output:<\/p>\r\n\r\n\r\n\r\n
\r\n

Array after inserting element at first position: array(‘i’,[1,1,3,6,12])<\/p>\r\n

index of last element: 3<\/p>\r\n<\/td>\r\n<\/tr>\r\n<\/tbody>\r\n<\/table>\r\n

When you need to add multiple items or an array of items ( of same data type as of array) to your array, use the extend() method like this

<\/p>\r\n\r\n\r\n\r\n
\r\n

# Example program to add multiple items using extend method<\/p>\r\n
\r\n

arr = array.array(‘i’,[1,6,23,67])<\/p>\r\n

arr.extend([3,56,2])<\/p>\r\n

print(‘array after extension: ’,arr)<\/p>\r\n<\/td>\r\n<\/tr>\r\n<\/tbody>\r\n<\/table>\r\n

Output:<\/p>\r\n\r\n\r\n\r\n
\r\n

Array after extension: array(‘i’,[1,6,23,67,3,56,2])<\/p>\r\n<\/td>\r\n<\/tr>\r\n<\/tbody>\r\n<\/table>\r\n

arrays<\/p>\r\n\r\n\r\n\r\n

# Example program for array concatenation<\/p>\r\n
\r\n

arr_1 = array.array(‘i’,[1,6,23,7])<\/p>\r\n

\r\n

print(‘New array after concatenation: ‘,arr_3)<\/p>\r\n<\/td>\r\n<\/tr>\r\n<\/tbody>\r\n<\/table>\r\n

Removing elements from the array<\/h3>\r\n

The last element from the array can be removed using the pop() method.<\/p>\r\n\r\n\r\n\r\n
\r\n

# Example program 1 for removing element from array<\/p>\r\n
\r\n

arr_1 = array.array(‘i’,[1,6,23,7])<\/p>\r\n

x = arr_1.pop()<\/p>\r\n

print(‘popped element from the array: ‘,x)<\/p>\r\n

print(‘length of array is now: ’)<\/p>\r\n<\/td>\r\n<\/tr>\r\n<\/tbody>\r\n<\/table>\r\n

Output:<\/p>\r\n\r\n\r\n\r\n
\r\n

popped element from the array: 7<\/p>\r\n

Length of array is now: 3<\/p>\r\n<\/td>\r\n<\/tr>\r\n<\/tbody>\r\n<\/table>\r\n

Now we will remove a specific element from the array using remove() method.<\/p>\r\n\r\n\r\n\r\n
\r\n

# Example program 2 for removing element from array<\/p>\r\n
\r\n

arr_1 = array.array(‘i’,[1,6,23])<\/p>\r\n

arr_1.remove(6)<\/p>\r\n

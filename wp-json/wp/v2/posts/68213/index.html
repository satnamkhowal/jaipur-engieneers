In java, the behaviour of a class is specified by the implemented interface.There are two such interfaces as follows:<\/p>\r\n\r\n

\r\n
<\/i> Comparable in Java<\/div>\r\n
<\/i> Comparator in Java<\/div>\r\n<\/div>\r\n

What is comparable In Java<\/strong><\/h3>\r\n

Comparable is used to sort objects in a natural ordering using the data members of the class.It compares one object with the other(itself) on the basis of single data member or attribute.The comparable interface is found at the java.lang. Comparable and have only one method, CompareTo(Object) which is responsible for sorting.<\/p>\r\nLet us now understand what is the CompareTo() method of Comparable in Java.\r\n\r\nWhat is the CompareTo() method In Java and how to use CompareTo()\r\n

The CompareTo() method is used to compare the current (this reference) object with the other(given) object.The CompareTo() method can sort the objects of the following types:<\/p>\r\n\r\n

\r\n
<\/i> String objects<\/div>\r\n
<\/i> Wrapper class objects<\/div>\r\n
<\/i> User-defined class objects<\/div>\r\n<\/div>\r\n

This method returns an integer value, a positive, a negative or a zero on the basis of comparison result.Here is how the result is decided<\/p>\r\n\r\n

\r\n
<\/i> positive integer: if the current object is greater than the given or specified object (lexicographically in case of Strings),it returns a positive number.<\/div>\r\n
<\/i> negative integer: if the current object is less than the given or specified object(lexicographically in case of Strings), it returns a negative number.<\/div>\r\n
<\/i> zero: if the current object is equal to the given or specified object(lexicographically in case of Strings), it returns zero.<\/div>\r\n<\/div>\r\nLet us understand the comparable interface for sorting with an example problem.\r\n\r\nJava Comparable Example<\/strong>\r\n\r\nA java program to compare working from the year of different employees.\r\n

Comparator interface In Java<\/strong><\/h3>\r\n
The Comparator interface is used to sort the objects of a user defined class by comparing one object with the other of the same type. Moreover, it sorts the objects which have the self tendency to sort themselves. The Comparator interface is present at java.util.Comparator.<\/em><\/p>\r\nUnlike Comparable, the Comparator uses two methods for sorting,\r\n
\r\n
<\/i> compare(Object obj1,Object obj2)<\/div>\r\n
<\/i> equals(Object element)<\/div>\r\n<\/div>\r\nThe compare(Object obj1, Object obj2), compares the two passed parameters with each other and returns,\r\n
\r\n
<\/i> Negative integer, if the first argument is less than the second argument<\/div>\r\n
<\/i> A positive integer, if the first argument is greater than the second argument and<\/div>\r\n
<\/i> Zero, if both the arguments are equal.<\/div>\r\n<\/div>\r\n
The second method equals(Object element), takes one positional argument as Object, and compares the given Object with the comparator.<\/p>\r\n
equals() method will return true if the passed object is also a comparator else returns false.<\/p>\r\n
The sort() method of the Collections class, takes comparator and invokes or calls the compare method of the Comparator interface for sorting the objects.<\/p>\r\nThe following steps are followed for sorting objects, with a comparator\r\n
\r\n
<\/i> Create a class and implement Comparable class on it<\/div>\r\n
<\/i> Make an instance of that class<\/div>\r\n
<\/i> Override the compare or compareTo method<\/div>\r\n
<\/i> Overload and invoke the sort method by passing the list and the instance of class(which implements comparable).<\/div>\r\n<\/div>\r\n

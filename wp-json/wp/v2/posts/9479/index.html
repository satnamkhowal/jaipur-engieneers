Hadoop was created out of necessity as the data from web exploded and ramped high beyond the ability to store in traditional systems. Hadoop is a open source software which enables processing of large set of data by distributing them among various systems and various locations. Hadoop is capable of handling not only of storing, processing & analyzing of hundreds of terabytes of data, but it can even handle petabytes of data generated.<\/p>\r\n

Hadoop introduced a new method of storing, processing and analyzing data in cloud rather than relying on hardware & physical systems. In short we can say, NO DATA is BIG for HADOOP to handle. So Hadoop helps major organizations to find meaningful data out of terabytes of data which was considered useless previously<\/p>\r\n\r\n

Hadoop Yarn:<\/strong>\u00a0Yet Another Resource Navigator. It assigns the storage space, CPU to all the applications running on the Hadoop cluster. This module of Hadoop acts as a Scheduler.<\/p>\r\n

Hadoop MapReduce:<\/strong>\u00a0A YARN based distributed processing for large set of data.<\/p>\r\n\r\n

Benefits of Hadoop:<\/strong><\/h3>\r\n

Eventhough different unrelated data are stored; Hadoop can fetch meaningful insights from this raw data and can help organizations with valuable analytics.<\/p>\r\n\r\n

Converting List To String With Iterative Method<\/p>\r\n

Here we will use for and while loops to iterate over the list and convert it to a string.<\/p>\r\n\r\n\r\n\r\n
\r\n

# Program to convert list to string using while loop<\/p>\r\n
\r\n

my_list = [‘HI’, ‘THERE’, ‘YOU’, ‘CAN’, ‘JOIN’, ‘WITH’, ‘ME’, ‘AT’, ‘FITA’]<\/p>\r\n

my_string = ”<\/p>\r\n

count = 0<\/p>\r\n

while count < len(my_list):<\/p>\r\n

      my_string += ‘ ‘+ my_list[count]<\/p>\r\n

      count += 1<\/p>\r\n

print(my_string)<\/p>\r\n<\/td>\r\n<\/tr>\r\n<\/tbody>\r\n<\/table>\r\n\r\n\r\n\r\n
\r\n

# Program to convert list to string using for loop<\/p>\r\n
\r\n

my_list = [‘HI’, ‘THERE’, ‘YOU’, ‘CAN’, ‘JOIN’, ‘WITH’, ‘ME’, ‘AT’, ‘FITA’]<\/p>\r\n

my_string = ”<\/p>\r\n

for i in my_list:<\/p>\r\n

     my_string += ‘ ‘+i<\/p>\r\n

print(my_string)<\/p>\r\n<\/td>\r\n<\/tr>\r\n<\/tbody>\r\n<\/table>\r\n

And now this can be further simplified if you don’t want to store the list as a string<\/p>\r\n\r\n\r\n\r\n
\r\n

# Program to convert list to string using for loop<\/p>\r\n

my_list = [‘HI’, ‘THERE’, ‘YOU’, ‘CAN’, ‘JOIN’, ‘WITH’, ‘ME’, ‘AT’, ‘FITA’]<\/p>\r\n

for i in my_list:<\/p>\r\n

    print(i,end=’ ‘)<\/p>\r\n<\/td>\r\n<\/tr>\r\n<\/tbody>\r\n<\/table>\r\n

All the above programs will have the same output as follows:<\/p>\r\n\r\n\r\n\r\n
\r\n

HI THERE YOU CAN JOIN WITH ME AT FITA<\/p>\r\n<\/td>\r\n<\/tr>\r\n<\/tbody>\r\n<\/table>\r\n

Notice when you add an integer to the my_list all the above programs will break, except if you convert the elements to a string.So try changing the elements to a string using str() method while concatenating just like this and you are good to go..<\/p>\r\n\r\n\r\n\r\n
\r\n

# Program to convert list to string using for loop<\/p>\r\n

my_list = [‘HI’, ‘THERE’,’CAN’, ‘YOU’, ‘JOIN’, ‘WITH’, ‘ME’, ‘AT’,2]<\/p>\r\n
\r\n

my_string = ”<\/p>\r\n

for i in my_list:<\/p>\r\n

   my_string += ‘ ‘+ str(i)<\/p>\r\n

print(my_string)<\/p>\r\n<\/td>\r\n<\/tr>\r\n<\/tbody>\r\n<\/table>\r\n

Converting List To String With join() method<\/h3>\r\n

You can join the lists with any character in between using the ‘character’.join(iterator) method.Here is an example<\/p>\r\n\r\n\r\n\r\n
\r\n

# Program to convert list to string using join method<\/p>\r\n
\r\n

my_list = [‘HI’, ‘THERE’, ‘YOU’, ‘CAN’, ‘JOIN’, ‘WITH’, ‘ME’, ‘AT’, ‘FITA’]<\/p>\r\n
\r\n

my_string = ‘ ‘.join(my_list)<\/p>\r\n

print(my_string)<\/p>\r\n<\/td>\r\n<\/tr>\r\n<\/tbody>\r\n<\/table>\r\n

Or like this if you don’t have to store the string.<\/p>\r\n\r\n\r\n\r\n
\r\n

# Program to convert list to string using join method<\/p>\r\n
\r\n

my_list = [‘HI’, ‘THERE’, ‘YOU’, ‘CAN’, ‘JOIN’, ‘WITH’, ‘ME’, ‘AT’, ‘FITA’]<\/p>\r\n
\r\n

print(‘ ‘.join(my_list))<\/p>\r\n<\/td>\r\n<\/tr>\r\n<\/tbody>\r\n<\/table>\r\n

Also you can directly pass the list to the join method as a parameter.<\/p>\r\n\r\n\r\n\r\n
\r\n

# Program to convert list to string using join method<\/p>\r\n
\r\n

print(‘ ‘.join([‘HI’, ‘THERE’, ‘YOU’, ‘CAN’, ‘JOIN’, ‘WITH’, ‘ME’, ‘AT’,’FITA’]))<\/p>\r\n<\/td>\r\n<\/tr>\r\n<\/tbody>\r\n<\/table>\r\n

You can either pass a comma or something else within the quotations of the join method.Now for an integer in the list we might have to change the above program so that all the elements are of string data type.<\/p>\r\n\r\n\r\n\r\n
\r\n

# Program to convert list to string using join method<\/p>\r\n
\r\n

my_list = [‘HI’, ‘THERE’, ‘CAN’,’YOU’, ‘JOIN’, ‘WITH’, ‘ME’, ‘AT’, 2]<\/p>\r\n
\r\n

print(‘ ‘.join(str(i) for i in my_list))<\/p>\r\n<\/td>\r\n<\/tr>\r\n<\/tbody>\r\n<\/table>\r\n

Alternatively, you can just print the list as a string with str() method and remove out the [] with strip() method<\/p>\r\n\r\n\r\n\r\n
\r\n

# Program to convert list to string using str and strip method<\/p>\r\n
\r\n

my_list = [‘HI’, ‘THERE’, ‘YOU’, ‘CAN’, ‘JOIN’, ‘WITH’, ‘ME’, ‘AT’, 2]<\/p>\r\n
\r\n

print(str(my_list).strip(‘[]’))<\/p>\r\n<\/td>\r\n<\/tr>\r\n<\/tbody>\r\n<\/table>\r\n

Or by removing first and the last element<\/p>\r\n\r\n\r\n\r\n
\r\n

print(str(my_list)[1:-1])<\/p>\r\n<\/td>\r\n<\/tr>\r\n<\/tbody>\r\n<\/table>\r\n

Converting List To String With List Comprehension<\/h3>\r\n

Here is how you would join the list with list comprehension.<\/p>\r\n\r\n\r\n\r\n
\r\n

# Program to convert list to string using list comprehension<\/p>\r\n
\r\n

print(‘ ‘.join([str(i) for i in [‘HI’, ‘THERE’, ‘CAN’,’YOU’, ‘JOIN’, ‘WITH’, ‘ME’, ‘AT’, 2]]))<\/p>\r\n<\/td>\r\n<\/tr>\r\n<\/tbody>\r\n<\/table>\r\n

Convert list to string with map() method<\/h3>\r\n

The map method takes 2 positional arguments, a method and an iterable.a method could be an int() or str() and an iterable could be a list, tuple string, set etc.It will then map or change the elements of the iterable to with the method provided.<\/p>\r\n

Here is an example for converting lists containing different data types to a string using map() and join() methods.<\/p>\r\n\r\n\r\n\r\n
\r\n

# Program to convert list to string using map and join method<\/p>\r\n
\r\n

my_list = [‘HI’, ‘THERE’, ‘CAN’, ‘YOU’, ‘JOIN’, ‘WITH’, ‘ME’, ‘AT’, 2]<\/p>\r\n
\r\n

print(‘ ‘.join(map(str, my_list)))<\/p>\r\n
\r\n

# or<\/p>\r\n
\r\n

print(‘ ‘.join(map(str, [‘HI’, ‘THERE’, ‘CAN’, ‘YOU’, ‘JOIN’, ‘WITH’, ‘ME’, ‘AT’, 2])))<\/p>\r\n<\/td>\r\n<\/tr>\r\n<\/tbody>\r\n<\/table>\r\n

Converting String to list<\/h3>\r\n

We have been converting list to strings, but you can also change string to list using the list() and split() method.<\/p>\r\n

Here is an example for list() method.<\/p>\r\n\r\n\r\n\r\n
\r\n

# Program to convert string to list using list() method<\/p>\r\n
\r\n

my_list = ‘HI THERE YOU CAN JOIN WITH ME AT 2’<\/p>\r\n
\r\n

print(list(my_list))<\/p>\r\n<\/td>\r\n<\/tr>\r\n<\/tbody>\r\n<\/table>\r\n

which will output<\/p>\r\n\r\n\r\n\r\n
\r\n

[‘H’, ‘I’, ‘ ‘, ‘T’, ‘H’, ‘E’, ‘R’, ‘E’, ‘ ‘, ‘Y’, ‘O’, ‘U’, ‘ ‘, ‘C’, ‘A’, ‘N’, ‘ ‘, ‘J’, ‘O’, ‘I’, ‘N’, ‘ ‘, ‘W’, ‘I’, ‘T’, ‘H’, ‘ ‘, ‘M’, ‘E’, ‘ ‘, ‘A’, ‘T’, ‘ ‘, ‘2’]<\/p>\r\n<\/td>\r\n<\/tr>\r\n<\/tbody>\r\n<\/table>\r\n

But to change the string as we had earlier we can use the split() method.<\/p>\r\n\r\n\r\n\r\n
\r\n

# Program to convert string to list using split() method<\/p>\r\n
\r\n

my_list = ‘HI THERE YOU CAN JOIN WITH ME AT 2’<\/p>\r\n
\r\n

print(my_list.split(‘ ‘))<\/p>\r\n<\/td>\r\n<\/tr>\r\n<\/tbody>\r\n<\/table>\r\n

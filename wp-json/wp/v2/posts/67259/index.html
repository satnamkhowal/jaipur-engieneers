Or with a python function it can be implemented as<\/p>\r\n\r\n\r\n\r\n
\r\n

#covariance between x and y<\/p>\r\n

def covar(x,x_mean,y,y_mean):<\/p>\r\n

covariance = 0.0<\/p>\r\n

for i in range(len(y)):<\/p>\r\n

covariance += (x[i] – x_mean) * (y[i] – y_mean)<\/p>\r\n

return covar<\/p>\r\n

 <\/p>\r\n

#variance for difference between actual and mean value<\/p>\r\n

def variance(values):<\/p>\r\n

return np.var(values)<\/p>\r\n

 <\/p>\r\n

# slope and intercept<\/p>\r\n

def coefficients(row_1,row_2):<\/p>\r\n

x_mean, y_mean = np.mean(row_1), np.mean(row_2)<\/p>\r\n

slope = covar(row_1,x_mean,row_2,y_mean)\/variance(row_1)<\/p>\r\n

intercept = x_mean – (slope * y_mean)<\/p>\r\n

return [slope, intercept]<\/p>\r\n

 <\/p>\r\n

def simple_linear_regression(df,test_values):<\/p>\r\n

predictions = []<\/p>\r\n

m, x = coefficients(df[[‘years’]],df[[‘per_capita’]])<\/p>\r\n

for i in test_values:<\/p>\r\n

y_values = x + m * i<\/p>\r\n

predictions.append(y_values)<\/p>\r\n

return predictions<\/p>\r\n<\/td>\r\n<\/tr>\r\n<\/tbody>\r\n<\/table>\r\n

You might notice the difference between the actual value of 2016 and the predicted value of 2016. This is known as mean squared error, and the correctness of the equation can be found with the R Square Method also known as coefficient of determination or coefficient of multiple determination. This R2can be calculated with the following formula.<\/p>\r\n

     R2=(yp-\u0233<\/strong>)(xp-x\u0305<\/strong> )<\/p>\r\n

If the more the R2is less than 1 the more the values are far the regression line.<\/p>\r\n

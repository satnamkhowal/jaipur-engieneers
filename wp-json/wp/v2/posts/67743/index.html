What Is Overloading In Python?<\/strong><\/h3>\r\n

Overloading is giving different definitions to a method or function in different places i.e., the method will work differently but with the same name.<\/p>\r\n

Overloading the method, prioritizes the DRY(Don’t Repeat Yourself) rule, by code redundancy, reusability. Overloading avoids complexities in code and improves code clarity.<\/p>\r\n

After understanding what is Overloading in python, let us now see what is operator overloading in python along with example programs.<\/p>\r\n

How to Overload Method In Python<\/strong><\/h3>\r\n

In python, you can overload the same method or function defined in a place, with a different number of arguments or zero arguments while using the same name at different places. This process is known as Method Overloading.<\/p>\r\n\r\n\r\n\r\n

Method Overriding<\/strong><\/h3>\r\n

Method overriding is when you are using the same method name, and the same number of arguments in the classes and usually in case of inheritance.<\/p>\r\n

Let’s say you want to give different discounts to your regular and occasional customers because regular customers know your previous prices well and are good at a bargain, although you can convince occasional customers with a less discount.<\/p>\r\n

Here’s a simple code that will have the same functionalities but different discount rate,<\/p>\r\n\r\n\r\n\r\n
\r\n

# Example program for Method Overriding<\/p>\r\n
\r\n

class RegularCustomer:<\/p>\r\n
\r\n

       def __init__(self, name, item, price, quantity):<\/p>\r\n

           self.name = name<\/p>\r\n

           self.item = item<\/p>\r\n

           self.price = price<\/p>\r\n

           self.quantity = quantity<\/p>\r\n
\r\n

     def discount(self):<\/p>\r\n

          return self.price * 0.3<\/p>\r\n
\r\n

class OccasionalCustomer(RegularCustomer):<\/p>\r\n

    def __init__(self, name, item, price, quantity):<\/p>\r\n

       super().__init__(name, item, price, quantity)<\/p>\r\n
\r\n

   def discount(self):<\/p>\r\n

       return self.price * 0.1<\/p>\r\n
\r\n

# common interface<\/p>\r\n

def cal_discount(object):<\/p>\r\n

    z = object.discount()<\/p>\r\n

    print(f'{object.name}\\’s discount will be {z}’)<\/p>\r\n

    print(f'{object.final()} is your final price’)<\/p>\r\n<\/td>\r\n<\/tr>\r\n<\/tbody>\r\n<\/table>\r\n

The above program has two different classes RegularCustomer and OccasionalCustomer.The __init__ method also known as the dunder or magic method is a constructor for the class and initializes the attributes to be used within the class.<\/p>\r\n

The super() charge method and the subclasses initializes all the attributes passed and all the methods of the base class into the child class.<\/p>\r\n

A discount method defined above for the regular customers calculate a 30 percent discount, whereas it has been defined again in the child class to return a 10 percent discount. This is method overriding, if we wouldn’t have defined the discount method again, it will calculate a 30 percent discount for both the types of customers.<\/p>\r\n

Let’s test the program now by creating objects of this class and calling methods,<\/p>\r\n\r\n\r\n\r\n
\r\n

cus_1 = RegularCustomer(‘Atufa’, ‘shoes’, 600, 1)<\/p>\r\n

cus_2 = OccasionalCustomer(‘Shireen’, ‘shoes’, 600, 1)<\/p>\r\n
\r\n

# passing the objects to common interface<\/p>\r\n

print(cal_discount(cus_1))<\/p>\r\n

print(cal_discount(cus_2))<\/p>\r\n<\/td>\r\n<\/tr>\r\n<\/tbody>\r\n<\/table>\r\n

The above program will now output<\/p>\r\n\r\n\r\n\r\n
\r\n

Atufa’s discount will be 180.0<\/p>\r\n

Shireen’s discount will be 60.0<\/p>\r\n<\/td>\r\n<\/tr>\r\n<\/tbody>\r\n<\/table>\r\n

Let’s now add one more method which will give us the final price of the program.<\/p>\r\n

Add this method only in the base class and you will be good to go..<\/p>\r\n\r\n\r\n\r\n
\r\n

def final(self):<\/p>\r\n

return (self.price – self.discount()) * self.quantity<\/p>\r\n<\/td>\r\n<\/tr>\r\n<\/tbody>\r\n<\/table>\r\n

This will now output as follows<\/p>\r\n\r\n\r\n\r\n

\r\n

Shireen’s discount will be 60.0<\/p>\r\n

540.0 is Shireen final price<\/p>\r\n<\/td>\r\n<\/tr>\r\n<\/tbody>\r\n<\/table>\r\n
